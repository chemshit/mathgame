# World Pet Wash

Türkçe, İngilizce ve Almanca destekli 3B tarayıcı oyunu prototipi. Node.js 22.12+ gerekir.

```sh
npm ci
npm run dev
npm run build
```

Karakter seçimi → parkta köpeği yakalama → zamanlama oyunu → baloncukları sürükleyerek yıkama → yıldız değerlendirmesi.

WASD / ok tuşları: ileri, geri ve dönüş. Boşluk: yakalama/zamanlama. Telefonda ekran düğmeleri kullanılır; yatay ekran önerilir. Yıkamada baloncukları köpeğin üzerine bırakın. Kaçışta köpeği yeniden yakalayıp yarım kalan yıkamayı baştan tamamlayın. En iyi yıldız sonucu tarayıcıda saklanır. Hesap veya sunucu gerekmez.

Fön, tüy kesimi, giydirme, altın/bütçe ve sahiplenme sonrası kişiselleştirme sonraki sürümlerdedir. Görseller özgün basit 3B geometrilerden oluşur. Üretim sürümü için mobil cihazlarda performans ve erişilebilirlik ayrıca doğrulanmalıdır.
